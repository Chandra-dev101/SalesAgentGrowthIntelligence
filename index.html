Semantic Model Build Guide

Step-by-step Fabric Copilot prompts — includes Fusion Community model

Step 1 — Create Semantic Model

Foundational semantic model for Fabric Copilot.
Build a semantic model called Sales Agent Growth Intelligence. Sources: 1. Agent consumption telemetry 2. M365 Copilot usage 3. Agent deployment projects 4. D365 Sales licensing 5. Customer master list Relationships: Customer, Tenant ID, Agent Name, Date Measures: Total Credits Consumed, Monthly Credits Consumed, MAU, PRU, Agent MAU, Consumption %, Unused Credits, Whitespace Seats Expose all measures for Power BI reporting.

Step 2 — Customer Profile Table

One row per customer with all key attributes.
Create a Customer Profile model. For every customer return: Customer name, Tenant ID, Industry, Seats, D365 Sales licenses, M365 Copilot licenses, Owned agents, Live agents, Pipeline agents, Total credits consumed. Create one row per customer.

Step 3 — Agent Ownership Logic

Ownership matrix with deployment status.
Determine all Sales-related agents owned by each customer. Include: Sales Qualification Agent, Sales Development Agent, Sales Opportunity Agent, Sales Research Agent, Sales Close Agent Return: Customer, Agent Name, Status (Live | Deploy | POC | Presales) Create ownership matrix.

Step 4 — Consumption Scoring

Composite score 0-100 with weighted metrics.
Create a consumption score from 0-100. Scoring: Credits consumed, MAU, PRU, Agent MAU, Growth trend Weighting: Credits 40%, MAU 20%, PRU 20%, Growth 20% Return: Customer, Consumption Score, Adoption Tier (Red | Yellow | Green)

Step 5 — Whitespace Logic

Biggest value play — identify untapped opportunities.
Identify whitespace opportunities. Rules: - D365 Sales Premium AND No Sales Agent consumption = High Whitespace - M365 Copilot AND Agent MAU < 10% = High Agent Whitespace - Unused credits > 1000 = Consumption Expansion Opportunity Generate whitespace score.

Step 6 — Next Agent Recommendation

Progression-based next-best-agent logic.
Generate next best agent recommendations. Rules: - No agents → recommend Qualification Agent - Qualification only → Opportunity Agent - Opportunity only → Close Agent - Opportunity + Close → Development Agent - Development only → Research Agent Return: Customer, Current Agents, Recommended Agent, Reason

Step 7 — Revenue Opportunity Model

Estimate expansion opportunity by category.
Estimate expansion opportunity. Inputs: Seats, Consumed credits, Unused credits, Installed products Categories: Activation, Expansion, Cross-Sell, Upsell Generate opportunity score 0-100.

Step 8 — Executive Report

Seven-page Power BI report layout.
Create executive report pages. Page 1: Executive Summary Page 2: Customer Intelligence Page 3: Agent Consumption Page 4: M365 Copilot Adoption Page 5: Whitespace & Expansion Page 6: Fusion Sales Agent Community (primary working tab) Page 7: Top Opportunities

Step 9 — Fusion Community Model ⭐

Dedicated model for Fusion/FastTrack/Community customers.
Create an additional report tab: Fusion Sales Agent Community Data Sources: Fusion agent project records, FastTrack Agent Deployment projects, Sales Agent Community customer list, Agent consumption telemetry, M365 Copilot usage, D365 Sales licensing Only include customers in: Fusion, Sales Agent Community, Agent Deployment projects Customer matching: TenantId, Customer Name, Customer Domain (fuzzy match with confidence score) Fusion Community Customer Profile — one row per customer: Customer Name, Tenant ID, Industry, Segment, Region, Seller, SA Owner, FastTrack Owner, Fusion Project Status/Type/Stage, D365 Sales Premium, D365 Sales Enterprise, Copilot for Sales, M365 Copilot, D365 Seats, M365 Copilot Seats, Agents Owned/Live/In Deployment/In POC, Total Agent Credits, Last 30 Day Credits, Last 90 Day Credits, Agent MAU, Copilot MAU, Copilot PRU, Unused Credits, Whitespace Seats, Consumption Score, Expansion Opportunity Score
